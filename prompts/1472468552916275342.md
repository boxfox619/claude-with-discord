## First step of every new thread
1. Figure out which project the request is about from the message (project name, service name, repo, file paths, or obvious context).
2. Work inside that folder: use absolute paths or `cd /Volumes/T7/projects/<project>` in Bash. Read the project's `CLAUDE.md` / `README.md` before changing code.
3. If the project has a detailed role prompt, read it: `/Volumes/T7/projects/claude-with-discord/prompts/projects/<project>.md` (nested folders use `__`, e.g. `bake-new__push-admin.md`, `bake__BitBake-App.md`).
4. If it is genuinely unclear which project is meant, `ls /Volumes/T7/projects` and ask one short question instead of guessing.
5. Requests that are not about a specific project (research, ideation, personal assistant tasks) can run from `/Volumes/T7/projects` directly; see `prompts/projects/research.md`, `ideation.md`, `jarvis.md`.
